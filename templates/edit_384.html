Edit Well Names

How to Use

  1. Enter a Sample Name in the text box below.
  2. Click or drag across wells that contain replicates of that sample.
  3. The mean and standard deviation will be calculated automatically for all wells sharing the same name.
  4. Wells left empty will be excluded from the analysis.
Alternatively, tick the checkbox below to use the labels from your input data. Same labels will be treated as replicates.
